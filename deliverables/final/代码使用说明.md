# 周期感知与互补融合异常检测：代码与数据

第 9 组：李思懿、翁汇坤。最终范围为 NAB 的 21 条真实序列、三类场景、22 个测试窗口。原始数据按 NAB MIT 许可随包提供，出处与许可位于 `data/raw/post-feedback-nab/`。

## 1. 最快复现

将“代码与数据”和“实验结果”两个 ZIP 解压至同一个普通本地目录，合并 `dw-periodic-ad/`。不要在云盘内运行模型、编译或启动数据库。

```bash
cd dw-periodic-ad
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python scripts/reproduce_submission.py
```

Windows 将 Python 路径换成 `.venv\Scripts\python.exe`。快速复现不需要 Java 或 IoTDB：它校验压缩包文件清单，使用归档的无损 Java 分数，重新选择 21 条序列的快慢模式、融合并评价。预期 `results/reproduced-submission/verification.json` 显示 `matched`、21 条及 231 项指标一致；总计 TP=15、FP=21、FN=7，事件 F1=0.517241，18 条慢模式、3 条快模式。

快速复现不是只读取汇总表，也不是模型重新拟合或新盲测。具体操作与边界见 `docs/最终版-测试用例与实验描述.md`。

## 2. 从原始数据完整重跑

在另一新目录中只解压代码与数据包，建立同样的 Python 环境，并将 Java 17 的 `java` 加入 PATH：

```bash
.venv/bin/python scripts/run_submission_experiment.py
```

入口依次运行数据筛选、7 种组件/外部方法拟合与校准、真实测试、归档分数导出，以及固定快、固定慢和最终选模式三种融合的评价。已有冻结选择时会拒绝覆盖。完整结果分别位于 `results/iteration2/final-nab/` 和 `results/refit-fusion/`。

代码包带有本次使用的 JAR；不要求为重跑先编译。重建 JAR 会改变字节指纹，应在新目录重新校准，不能手改归档指纹。离线实验不会启动或修改数据库。

## 3. 代码入口

| 路径 | 作用 |
| --- | --- |
| `detector-core/src/` | 周期模板、有界更新、MAD、EWMA、稳健 AR 在线评分 |
| `detector-udf/src/` | IoTDB Tree UDF，独立实例状态，四种单列输出 |
| `runner/src/` | CSV 评分、数据库一致性与成本比较 |
| `scripts/predictive_baseline.py` | 训练前缀拟合 Huber AR 与独立数值参考 |
| `scripts/production_scoring.py` | 把冻结参数转换为 Java 配置、调用评分并核对缓存 |
| `scripts/literature_baselines.py` | 因果 SR、有界左侧 Matrix Profile |
| `scripts/benchmark_iteration2.py` | 统一组件与外部 baseline 校准、冻结与测试 |
| `scripts/nab_fusion.py` | 两路归一化均值、背景阈值与验证模式选择 |
| `scripts/reproduce_submission.py` | 无损分数上的最终模式重选与事件评价 |

| `configs/expanded-manifest.json` | 全部 47 条候选、纳入/排除原因、数据哈希 |

最终融合是 Python 实验模块；Java/UDF 实现的是组成它的周期、EWMA、稳健 AR 等组件，不宣称完整融合已移入 UDF。IF/LOF 使用 scikit-learn 1.7.2；SR 不是 SR-CNN，Left-MP 不是完整 DAMP 实现。论文 DOI 与实现区别见 `docs/最终版-论文与实现来源.md`。

兼容脚本使用本项目 macOS/Homebrew 环境脚本。归档已有 83 项相关 Java 用例、7 项文献基线数学/因果用例、120×200 输入默认兼容记录和真实数据库核验。本次打包没有再执行全量测试。

## 5. IoTDB 实验（可选，本机）

库内外实验使用 IoTDB 2.0.11 Tree、Java 17。以下命令面向已验证的 macOS/Homebrew 环境；要求安装 OpenJDK 17、Python 3.12，并确保所需本地端口未被其他服务占用。

```bash
.venv/bin/python scripts/setup_runtime.py
source scripts/env.sh
bash scripts/iotdb.sh start
bash scripts/deploy_detector.sh
.venv/bin/python scripts/benchmark_adaptive_database.py --output results/local-ar-performance
```

`setup_runtime.py` 下载并校验 Maven/IoTDB，配置到项目 `.local/`，不启动服务；`iotdb.sh start` 才启动本机服务；`deploy_detector.sh` 将附带 UDF 部署到本项目数据库并保留备份。性能命令写入项目专属性能设备，不删除已有数据，不要用于生产库。需要结束本项目服务时执行 `bash scripts/iotdb.sh stop`，脚本检查端口归属。

真实 AR/周期组件分别在 3,168/8,976 个有效评分点上完成四输出库内外对照。性能负载为 1 万、10 万、100 万点的公开 NAB 平铺输入，2 轮预热、5 轮测量；三规模校验和一致，但没有观察到 UDF 加速。它测量 AR 组件，不包含 Python 融合总时延。

## 7. 文档重建

主文档和 12 页 PPT 已交付。确需重建时，先合并两个包，再安装 `requirements-docs.txt` 并运行：
