# 代码使用说明

本项目根目录为 `dw-periodic-ad`，由第 9 组（李思懿、翁汇坤）完成。仓库通过 Git 克隆获取，建议在普通本地磁盘路径下编译与运行，避免在同步云盘目录中执行构建。

## 1. 环境依赖

- **基础环境**：Java 17、Maven 3.9.x、Python 3.12
- **可选组件**：Apache IoTDB 2.0.11（Tree 模式，仅在需要复现数据库端 UDTF 验证与性能实验时使用）
- **验证环境**：项目配套 Shell 脚本已在 macOS / Homebrew 环境下完成验证。

## 2. 标准复现流程

在仓库根目录下依次执行以下命令，完成虚拟环境创建、依赖安装、Java 模块打包、NAB 数据集准备与完整实验运行：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
mvn -DskipTests package
.venv/bin/python scripts/prepare_expanded.py --download
.venv/bin/python scripts/run_submission_experiment.py
```

### 运行与目录说明

1. **数据集版本锁定**：`--download` 参数会自动拉取并固定本实验所使用的 NAB 官方仓库版本。Git 仓库本身不存储原始数据（raw）与模型缓存文件。
2. **输出保护机制**：若本地已存在 `results/iteration2/final-nab/selection.json`，完整实验入口 `run_submission_experiment.py` 会拒绝覆盖已有结果；如需从头重跑完整流程，请在新克隆的工作目录中执行。
3. **无数据库依赖**：上述主实验流程纯离线运行，不会启动或停止 IoTDB 服务。实验结果分别输出至 `results/iteration2/final-nab` 与 `results/refit-fusion`。
4. **基于归档结果的快速重算**：历史离线实验数据在本地另行归档保存。若当前工作区已合并代码、数据与实验结果归档，且存在 `results/submission/nab-replay` 目录，可直接运行以下命令重选 21 条序列的模式并计算评价指标（该流程直接基于归档分数重算，不重新拟合模型）：
   ```bash
   .venv/bin/python scripts/reproduce_submission.py
   ```
5. **最终交付物**：最终提交材料位于 `deliverables/final` 目录下，其中说明文档统一为 Markdown（含文档引用的两张 PNG 图表），展示文件保留 PPTX（不含讲稿）。

## 3. 代码结构与模块职责

- `detector-core`：纯 Java 实现的核心检测算子库，包含周期基线、限幅处理、MAD 尺度估计、EWMA 平滑及稳健自回归（robust AR）模块。
- `detector-udf`：面向 IoTDB Tree 模式的 UDTF 封装，按序列维护独立状态实例，IoTDB 依赖以 `provided` 作用域引入。
- `runner`：支持 CSV 离线批处理与数据库读写的运行器模块。
- `scripts/benchmark_iteration2.py`：统一负责 7 种基础方法的训练、阈值校准与指标评价。
- `scripts/nab_fusion.py`：纯 Python 实现的快慢分支融合模块（当前融合逻辑保留在 Python 层，未合并入单一 Java UDTF 中）。
- `scripts/evaluation.py`：定义事件合并、窗口命中判定与指标计算口径。
- `configs/expanded-manifest.json` 与 `configs/iteration2.json`：分别记录候选序列来源筛选元数据与实验评测协议配置。

## 4. IoTDB 数据库端可选验证流程

数据库端评测为可选流程，非主实验结果复现的必做步骤。如需验证 UDTF 在 IoTDB 2.0.11 Tree 模式下的数值一致性与查询耗时，可在仓库根目录下依次执行：

```bash
.venv/bin/python scripts/setup_runtime.py
source scripts/env.sh
bash scripts/iotdb.sh start
bash scripts/deploy_detector.sh
.venv/bin/python scripts/benchmark_adaptive_database.py --output results/local-ar-performance
bash scripts/iotdb.sh stop
```

**注意事项**：该脚本固定连接本地 `127.0.0.1` 测试实例，并在库内创建性能测试所需的设备与时间序列，仅用于本地实验验证，请勿指向生产环境实例。实验结束后请执行 `bash scripts/iotdb.sh stop` 停止服务。
